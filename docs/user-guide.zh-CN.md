# 使用指南

[返回 README](../README.zh-CN.md) · [English](user-guide.md)

## 模型与配置

在**设置**中选择 API 类型、地址、模型和凭据。Open Builder 提供以下适配器：

| API 类型          | 协议                    | 默认地址                                    |
| ----------------- | ----------------------- | ------------------------------------------- |
| OpenAI Compatible | 兼容 Chat API           | `http://localhost:11434`                    |
| OpenAI            | Responses API           | `https://api.openai.com`                    |
| Anthropic         | Messages API            | `https://api.anthropic.com`                 |
| Google            | Generative Language API | `https://generativelanguage.googleapis.com` |

模型需要支持工具调用，截图工作流还需要图像输入能力。模型与推理强度选项取决于所选服务的能力。

API 配置与密钥保存在浏览器本地存储中。高级设置支持最多 32,000 字符的自定义指令，用于生成请求，包括 Plan 和子代理。自定义指令不能授予工具权限或覆盖模式限制，请勿在其中填写凭据。

### 桌面端本地 CLI

1. 按对应服务的安装流程安装 Codex、Claude、Pi 或 Antigravity，并完成登录。
2. 打开**设置 → 模型 → 运行时 → 本地 CLI**，选择服务。自动检测失败时可使用**选择程序**。
3. 检查状态并选择模型，使用**重新扫描**刷新安装检测与模型列表。

Open Builder 在启动任务前检查可执行文件、结构化协议和隔离能力。如果就绪状态提示“首条消息将验证登录”，代表凭据或网关仍需真实推理请求验证，可能消耗额度。模型目录不完整时，已保存的选择会保留并标为**未验证**，不会静默更换服务。

CLI 通过受限的本地回环桥接调用 Open Builder 项目工具。项目仍位于应用虚拟文件系统中，不向模型开放 CLI 原生 shell 和文件系统工具。本地 CLI 不等于离线模型：提示词、附件和工具结果仍可能发送给它配置的模型服务。

各服务的差异：

- **Codex** 在符合条件的 Chat 请求中支持原生图像生成和参考图编辑。
- **Antigravity（`agy`）** 需要结构化无界面运行协议，支持原生文生图，不支持参考图编辑。
- **Claude** 和 **Pi** 不提供原生图像生成工具。
- **Pi** 使用通过 `/login` 保存到 `~/.pi/agent/auth.json` 的凭据。子进程会移除服务 API Key 环境变量，并拒绝 `models.json` 中的内联、环境变量解析或命令解析凭据。Pi 没有原生网页搜索工具，需要选择明确的搜索服务。

生成图片先保留在对话中，明确导入后才进入已初始化的项目。各服务的会话相互隔离；安装、配置、模型或协议变化导致不兼容时，会创建新会话。

只要同一桌面进程仍在运行，页面刷新后可以重连原 CLI 任务。已确认的工具结果只回放，不重复执行；无法确认副作用时停止恢复。退出或崩溃会结束这一恢复窗口。实现与排查记录见[流式输出与恢复](local-cli-streaming.md)和[诊断文档](local-cli-diagnostics.md)。

## 项目工作流

**编程**直接操作项目文件；**计划**先探索项目，获得方案批准后再写入；**设计**准备视觉上下文，生成可运行的界面或产品原型。模式按项目记忆，从 Design 进入 Plan 后，批准方案会返回 Design。

可以将 ZIP 或项目文件夹导入新会话，也可以在项目模板库保存可复用副本。导入前会在本地检查文件和资源完整性、过滤敏感路径并脱敏凭据，然后展示文件统计和预览模式。检查通过即可导入，当前项目及聊天历史会保留。支持预览的项目在导入后启动 Sandpack，并单独显示编译状态；编译失败或网络超时不影响已导入文件，可以继续编辑或重试预览。不受当前 Sandpack 支持的框架和版本会以代码模式导入，可在详细信息中查看原因。保存模板前会展示被排除的敏感路径和已脱敏凭据，不复制聊天历史或运行时会话。

源码下载保留项目文件和托管资源。静态部署 ZIP 支持纯静态站点及兼容的 Vite 4 前端项目；兼容构建面向现代浏览器，关闭压缩和 CSS 拆分，不执行自定义构建脚本或类型检查，也不生成 SSR/Node 部署包。部署时请按站点需要配置基础路径与 SPA 路由。

### 设计画布

单页项目直接显示“预览／代码”，保留设计模式与设计工具。蓝图包含两个及以上页面时显示画布，尚未完成的页面也计入页面数。

- 单击页面画板选择编辑上下文，切换代码标签查看对应源码。
- 双击画板或按 Enter 进入交互预览，返回画布时保留页面运行状态。
- 拖动画板并对齐吸附、平移画布，或切换桌面、平板和手机视口。
- 画板位置与视角按会话分支保存在本地，不修改源码、快照或导出内容。

画布图片是临时的完整页面预览，不是评审证据。新的完整产品原型使用 `vite-react-ts-prototype` starter，内置 Hash 路由与可重置的共享模拟数据。

根目录 `design-project.json` 记录页面、路由、共享 UI、流程和已提交进展。蓝图可以逐步完善，动态路由需要具体的预览路径。v1/v2 蓝图继续可读，编辑时迁移到 v3，并保留历史检查点及可安全保留的默认预览地址。产品目标和目标用户通过正常 Design 请求维护，`/continue` 从当前文件重建上下文。

### 设计系统与 Token

可以选择 36 套内置视觉参考、导入设计包，或根据名称和三组规则创建自定义系统。**自动**会让一次隔离的模型决策选择系统或**无**。为已有项目选择系统后会开始应用流程，空项目则将其用于下一次 Design 请求。

导入包由 `manifest.json`、`DESIGN.md` 和 `tokens.css` 组成，保存前会校验，且不静默覆盖已有 ID。单独存在的旧版 `DESIGN.md` 在明确升级前仅作为视觉参考。Token 修改可以先实时预览，保存时更新项目文件并创建快照。

### 元素点选

在交互预览中点击**在预览中点选元素**，再选择要在下一条消息中描述的元素。稳定的 `data-ob-id` 有助于定位，但并非必需；未标记元素会使用有界的运行时路径和邻近锚点。

点选支持以下 19 种内置模板：

| 类型           | 模板                                                  |
| -------------- | ----------------------------------------------------- |
| 静态           | `static`                                              |
| Vite           | `vite`                                                |
| Vite React     | `vite-react`、`vite-react-ts`                         |
| Vite Preact    | `vite-preact`、`vite-preact-ts`                       |
| Vite Vue       | `vite-vue`、`vite-vue-ts`                             |
| Vite Svelte    | `vite-svelte`、`vite-svelte-ts`                       |
| React          | `react`、`react-ts`                                   |
| Vue            | `vue`、`vue-ts`                                       |
| 其他浏览器模板 | `svelte`、`solid`、`angular`、`vanilla`、`vanilla-ts` |

Static/Vite 项目需要带 body 元素的根级 `index.html`；其他模板使用可执行的 `package.json.main`，也支持模板隐式提供的默认入口。自定义 Angular CLI 入口配置、无法确认入口、`nextjs`、`astro`、`node`、`test-ts` 和纯代码项目仍不支持点选，界面会说明原因。桥接代码不会进入保存文件和导出内容。

## 截图与评审

预览工具栏的 **Camera 图标**提供**当前区域**、**完整页面**和**指定区域**截图，导出为原始 CSS 像素尺寸的 PNG。指定区域会冻结当前视口，拖动框选后导出；可重新框选或按 Esc 取消。截图保留当前输入与滚动状态，桌面端可选择保存位置，浏览器端直接下载。

**批注预览**可截取当前视口或完整已渲染页面。添加形状、箭头、文字或画笔标记后，点击**添加到消息**，将合成图片附加到输入框，不自动发送。绘制内容是临时状态，取消或切换会话、分支、检出状态时会丢弃。

`capture_preview_sequence` 工具可按 1–5 个递增时间点采样当前预览，时间范围为 0–30,000 毫秒。采样保留当前交互状态，不刷新或导航，并报告实际时间与部分失败。历史只保存摘要，不保存图片字节。

完整页面截图仅覆盖当前已渲染 DOM，不自动展开内部滚动容器、虚拟列表或无限内容。视频、WebGL、跨域内嵌页面及外部资源存在截图限制。工具采集的评审证据可能为适配传输限制而等比缩小，用户导出的 PNG 保留原始 CSS 像素尺寸。

Design Review 可以使用上传截图，或采集声明的原型页面与视口。评审只读取文件并返回问题，不能修改文件或调用外部工具；自动设计评审也只报告结果，不改动代码。选择问题并点击**应用所选修复**后，才会开始正常 Design 任务。未采集目标保持未评审，源码变更后证据过期；旧场景级报告需要重新进行页级评审。采样 DOM 诊断不等同于完整的可访问性审计。

系统设置中的**自动 QA**默认关闭，同时控制编程模式自动 QA 与设计模式自动设计审查。关闭时取消未完成的自动设计审查，手动审查仍可使用，已完成报告继续保留；重新开启只影响后续生成。

## 历史与存储

快照保留项目文件、可用的托管资源，以及已记录的对话上下文和 Design 状态。检出后继续开发会创建新分支，原有后续记录仍保留；`/fork` 则创建独立会话。旧快照可能缺少完整上下文或 Design 历史。

无需切换当前项目，即可从消息或快照历史下载对应版本的源码 ZIP。新快照会排队准备归档，旧版本按需构建。归档存储需要 OPFS 和 Web Locks，打包失败可以重试。

存储治理提供用量查看，以及会话、快照、归档、设计系统、画布偏好和托管图片的清理操作。为避免跨标签页竞争，图片在最后一个可见引用被移除后仍可能保留字节，**清除全部数据**会清理这些存储。桌面目录导出会创建新目录，不提供与本地文件系统的双向同步。

## MCP、Skills、搜索与媒体

通过聊天工具栏管理 MCP 与 Skills。远程 HTTPS MCP 支持 Streamable HTTP、SSE、静态请求头与 OAuth，桌面端另支持 stdio。服务和工具可以分别启用，工具定义变化后需要审核；Plan 与子代理仅获得模式和权限允许的工具。

启用的 Skill 只向自动发现提供元数据，完整指令通过 `read_skill` 或下一条消息的明确选择加载。所选 Skill 同时适用于子代理，并在发送后清空。导入的 Skill 默认不启用自动发现。Skill 脚本需要桌面能力、开发者开关和逐次批准。

默认搜索服务为 Firecrawl，也可选择 Tavily、Exa 或受支持服务的原生搜索。网页读取失败时可以回退到 Jina Reader。图片搜索支持 Pixabay 与 Unsplash，请按所选服务配置凭据。

托管的 **Agnes AI** 集成通过本地 API Key 和逐工具批准提供图像生成与文生视频。结果以远程媒体显示在对话中，不自动写入项目文件。视频轮询仅在来源会话处于活动状态时运行，重启应用后不会恢复；仍可手动查询状态。仅图像生成可单独向子代理开放。

消息可附加图片、文本文件与 PDF。新本地图片默认以 `0.85` 质量压缩一次，PDF 处理取决于模型支持。Pi 遇到不支持的二进制工具结果时会明确报错，不会静默转为文字摘要。

## 指令与快捷键

| 指令                   | 行为                                  |
| ---------------------- | ------------------------------------- |
| `/new` / `/fork`       | 新建会话 / 复制当前会话与项目         |
| `/clear` / `/reset`    | 清除聊天上下文 / 批准后重置会话与项目 |
| `/compact`             | 压缩对话上下文                        |
| `/health` / `/review`  | 检查项目健康状态 / 请求项目审查       |
| `/continue` / `/retry` | 继续未完成工作 / 重试最近一次生成     |

| 快捷键       | 行为                           |
| ------------ | ------------------------------ |
| `Cmd/Ctrl+K` | 命令面板                       |
| `Cmd/Ctrl+N` | 新建会话                       |
| `Cmd/Ctrl+,` | 设置                           |
| `Cmd/Ctrl+/` | 聚焦输入框                     |
| `Esc`        | 优先关闭命令面板，否则停止生成 |

## 原生应用构建

请先安装 Rust 与 [Tauri 平台依赖](https://tauri.app/start/prerequisites/)。移动端仍为实验性，不提供本地 CLI、stdio MCP 和 Skill 脚本执行。

```bash
pnpm tauri:build

# 每个移动端目标首次使用时执行 init。
pnpm tauri ios init
pnpm tauri:ios:dev
pnpm tauri:ios:build

pnpm tauri android init
pnpm tauri:android:dev
pnpm tauri:android:build
```

架构术语与贡献流程见 [CONTEXT.md](../CONTEXT.md) 和 [CONTRIBUTING.md](../CONTRIBUTING.md)。
